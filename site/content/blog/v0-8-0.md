v0.8 was planned as the mobile release, and it is one. It also became the
release where Rux stopped running someone else's script engine. Both halves
landed in the same milestone, and this post covers both.

## Mobile

**An Android app without Android Studio or Gradle.** `rux build --target
android` produces an APK, and `rux run --device` installs it on a phone or an
emulator, starts it, and stays: every save is sent down an `adb reverse` socket
and the app reloads on the route it was on, in about three seconds with no
build. `rux doctor` says what the machine needs for any of this and the one
command that installs what is missing.

**`rux.toml` and `rux build`.** One manifest, three targets: `desktop`,
`android` and `web`. The manifest carries the app's name, id and version, its
launcher icon and the colour behind its splash screen, the link scheme and hosts for deep links, and, since
this week, a `[window]` table for a desktop app's size and limits.

**Touch for real.** Kinetic scrolling with a velocity taken from the last 100 ms
of the path, the gesture vocabulary driven on a phone with four fingers down at
once, and an axis rule that decides once, on direction, whether a drag inside a
scrolling list belongs to the list or to the element.

**Inputs and forms, finished.** Field attributes and events (`disabled`,
`readonly`, `maxlength`, `autofocus`, keyboard hints, `@input`, `@change`,
`@focus`, `@blur`), `number`, `switch`, `slider` and `date` controls, the
platform's own select and date pickers, the platform's own selection toolbar on
Android, and forms as `<view role="form">` with `@submit`, Next and Go on the
keyboard's action key, and checks whose results land in script. The same work
was then carried into a phone's browser.

**Coming back where it was.** When Android ends an app in the background, or a
phone's browser discards a tab, the app returns on the same route, at the same
scroll, with every field's text and the focused field's caret. A password never
comes back. No handler runs while the page is put back, as a browser refilling a
form runs none.

**The operating system's answers.** Safe-area insets, orientation, density,
`prefers-reduced-motion` and `prefers-color-scheme`, all as CSS. Reduced motion
went first, because v0.7 shipped an animation system that never asked.

## A language of its own

**Rhai is gone.** Rux now has its own parser, its own type checker, a typed
intermediate representation, and its own interpreter running every script. The
reference for the language it implements is written down in full, with every
rule marked as kept from before, changed or new.

**Types that are checked.** `int` and `float` are different types, `/` always
gives a `float`, and `intDiv` truncates. The empty value is spelled `none`, and
`T?` means it may be absent. `Result<T, E>`, generic functions and generic type
declarations, and `try`/`catch` with a Rux `Error`. A template is checked against
its script, and a prop is checked when the program runs. An untyped value says
so rather than passing silently.

**`async fn` and `await`.** A handler calls an async function; the function
awaits; the answer wakes the window. A task belongs to whatever started it, so a
component closed while its task waits writes nothing.

**Modules and stores.** A file with no template is a module. A store is shared
state that every importer reads, and only the store's own functions change it.

**Native modules.** Rust in a `native/` crate beside `rux.toml`, exported with
`#[rux::export]` and `#[rux::resource]`, is called from script by name. This is
the door for anything Rux does not do itself.

**Release builds compile functions to Rust.** The interpreter still loads every
file, and where a function has compiled code it calls that instead.

**Faster.** Measured in the same window harness, release builds: summing 10 000
records went from 18.6 ms a frame under rhai to 3.6 ms compiled, about 5×
faster, and filtering 2 000 records from 17.0 ms to 1.2 ms, about 14× faster. A
300-row list that took 78 ms a frame before any of this work now spends 0.08 ms
in script. Records are fixed slots in declaration order, so in the cost bench a
records sum that took 2.6 ms at the start of the compiler work takes 41 µs.

## What breaks

Most of the language change is a rewrite `rux fmt` performs: `number` becomes
`float`, `null` becomes `none`, and `#{` becomes `{`, since a brace followed by a
name and a colon is a map, as in JavaScript. Some of it is not: an unknown
`type=` on an input is an error, an attribute nothing reads is an error, a
component tag may pass only the props the component declares, and a plain
top-level `let` is read-only. `rux run` now reads the `rux.toml` above the file
it runs. `rux check` names every one of these.

## The bug found on the last day

A web page that came back from a reload showed an older value in a field than
the one it was left with. Choose a fruit, and the select's `@change` writes
"fruit plum" into a log field; choose a date, and the log becomes "day
2026-07-09"; reload, and the log reads "fruit plum".

Restoring a page put every field back, and then ran the select's `@change` again
so that anything derived from the choice was rebuilt. That handler wrote over the
log. The date's `@change` was not run again, so the replay was not even in the
order the person had made the changes. The same code runs on Android. The fix was
a decision rather than a patch: nothing runs while a page is put back.

It was found by driving a table of cases written a month earlier, again, on a
tree whose interpreter, IR and layout had all been replaced since. The test suite
was green throughout, at 1165 tests.

## What this release is not

**It has not been on a phone since September.** Every mobile feature above was
driven on the Android emulator, and many on a phone, until the phone used for
this work went away on 2026-09-25. The cases that need one, among them the
native selection handles, the keyboard's action labels, and the phone's own
browser, are listed in the user tests as unverified, each with that reason.

**No iOS.** It needs a Mac to build and a device to drive, and this project has
neither.

**`rux` still installs through `cargo`.** Distribution without a Rust toolchain
was dropped from this milestone.

**Two fingers are reported, not interpreted.** Pinch and rotate move to v0.9,
with the device survey `rux doctor` was meant to gain. Both want a phone to be
judged on.

## Next

list virtualization and the rest. Its order is now set by the first application
